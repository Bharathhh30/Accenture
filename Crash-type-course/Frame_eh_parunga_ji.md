## 📌 Section 1: Common Applications & MS Office (Questions 1 – 30)

#### **1. Which keyboard shortcut is used to copy selected content?**

* A) Ctrl + X
* B) Ctrl + C
* C) Ctrl + V
* D) Ctrl + Z
* **Answer:** **B) Ctrl + C**
* **Explanation:** Ctrl + C copies selected items to the clipboard. Ctrl + X cuts, Ctrl + V pastes, and Ctrl + Z undos.

#### **2. Which shortcut is used to undo an action?**

* A) Ctrl + Z
* B) Ctrl + Y
* C) Ctrl + U
* D) Ctrl + R
* **Answer:** **A) Ctrl + Z**
* **Explanation:** Ctrl + Z reverses the most recent action. Ctrl + Y redos, Ctrl + U applies underline, and Ctrl + R right-aligns text in MS Word.

#### **3. Which feature in MS Word creates personalized documents for many recipients?**

* A) Track Changes
* B) Mail Merge
* C) WordArt
* D) Format Painter
* **Answer:** **B) Mail Merge**
* **Explanation:** Mail Merge merges a base document with a database/spreadsheet to produce personalized letters or emails.

#### **4. Which Word feature records additions, deletions, and formatting edits?**

* A) Track Changes
* B) Mail Merge
* C) Word Count
* D) Page Break
* **Answer:** **A) Track Changes**
* **Explanation:** Track Changes marks all revisions made during document reviewing.

#### **5. Which paragraph alignment aligns text with both left and right margins?**

* A) Left
* B) Right
* C) Center
* D) Justify
* **Answer:** **D) Justify**
* **Explanation:** Justification adjusts word spacing so text reaches both left and right margins evenly.

#### **6. What is a header in MS Word?**

* A) Text appearing at the bottom of the page
* B) Text appearing at the top of the page
* C) A document title only
* D) Hidden text
* **Answer:** **B) Text appearing at the top of the page**
* **Explanation:** The header area resides in the top margin of a document and repeats across pages.

#### **7. Which feature copies formatting from one selection and applies it to another?**

* A) Format Painter
* B) Mail Merge
* C) WordArt
* D) AutoCorrect
* **Answer:** **A) Format Painter**
* **Explanation:** Format Painter duplicates visual formatting (font, size, color, paragraph spacing).

#### **8. Which shortcut saves a document?**

* A) Ctrl + R
* B) Ctrl + Alt
* C) Ctrl + S
* D) Ctrl + P
* **Answer:** **C) Ctrl + S**
* **Explanation:** Ctrl + S saves changes to the current file. Ctrl + P opens the print dialog.

#### **9. What does Ctrl + A do in MS Word?**

* A) Selects all content
* B) Aligns text
* C) Opens a file
* D) Saves a file
* **Answer:** **A) Selects all content**
* **Explanation:** Ctrl + A highlights the entire document content.

#### **10. Which feature starts document content on a new page?**

* A) Page Break
* B) WordArt
* C) Track Changes
* D) Format Painter
* **Answer:** **A) Page Break**
* **Explanation:** Page Break forces subsequent text to move to the top of the next page.

#### **11. Which symbol begins a formula in MS Excel?**

* A) `#`
* B) `@`
* C) `=`
* D) `&`
* **Answer:** **C) `=**`
* **Explanation:** All functional expressions and mathematical operations in Excel start with `=`.

#### **12. Which function calculates the total sum of a range of numbers?**

* A) COUNT
* B) SUM
* C) AVERAGE
* D) TOTAL
* **Answer:** **B) SUM**
* **Explanation:** `SUM` adds up numerical cell values in a specified range.

#### **13. What does `=AVERAGE(A1:A5)` calculate?**

* A) Total sum
* B) Maximum value
* C) Arithmetic mean
* D) Total number of cells
* **Answer:** **C) Arithmetic mean**

#### **14. Which Excel function counts cells containing numeric values only?**

* A) COUNTA
* B) COUNT
* C) SUM
* D) NUMCOUNT
* **Answer:** **B) COUNT**
* **Explanation:** `COUNT` ignores text and counts only cells with numeric data. `COUNTA` counts all non-empty cells.

#### **15. What does the `COUNTA` function count?**

* A) Only numbers
* B) Only formulas
* C) Non-empty cells
* D) Empty cells
* **Answer:** **C) Non-empty cells**

* A) Relative
* B) Absolute
* C) Mixed
* D) Invalid
* **Answer:** **B) Absolute**

* A) Deletes all slides
* B) Applies consistent formatting to slides

* **Answer:** **B) Applies consistent formatting to slides**

* C) Transition applies only to text

* **Answer:** **B) Animation applies to slide objects; Transition occurs between slides**

* A) F2

#### **30. What is BCC used for in email communication?**

* C) Encrypting email content
* D) Blocking spam
* **Answer:** **B) Hiding recipient email addresses from other recipients**
* **Explanation:** BCC (Blind Carbon Copy) sends copies to recipients without revealing their email addresses to anyone else on the thread.
