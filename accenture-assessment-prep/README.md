# Accenture Technical Assessment — Study Pack

This is a topic-by-topic preparation pack for a **general entry-level technical MCQ assessment**. It is designed for learning and timed practice, not as a prediction of the exact paper.

## Important about “previous-year” and 2026 questions

I could not verify an authoritative public archive of completed Accenture assessment questions. Accenture's [official recruiting FAQ](https://www.accenture.com/in-en/careers/explore-careers/area-of-interest/journey-to-accenture) does not publish one universal fresher MCQ paper. One 2026 preparation provider reports a 45-question technical mock split into 12 Common Applications/MS Office, 22 Pseudocode, and 11 Network Security/Cloud questions; another 2026 candidate account confirms broad topics (DSA, DBMS, cloud, networks, MS Office, pseudocode) but explicitly does **not** recall the MCQ count or exact MCQs. Older candidate write-ups describe a combined cognitive/technical test instead. These sources are useful signals, not an official blueprint.

Accordingly, the folder questions are **original practice questions**, not claimed verbatim past-paper, leaked, or confirmed 2026 questions. The [source-informed 45-question mock](11-source-informed-mock/README.md) follows one commonly published topic split so you can practise a realistic mix, while keeping the changing-pattern caveat visible. Use your own invitation and recruiter instructions for exact sections and timing.

## Suggested study order

1. Start with pseudocode and programming fundamentals.
2. Study networking, cloud, and security.
3. Review Office applications and core CS (OOP, data structures, DBMS, OS).
4. Attempt each question set without looking at the key; record missed concepts.
5. Revisit missed concepts, then retake the set under a timer.

**Practice strategy:** For output-tracing questions, write down variable values after every statement. For factual questions, learn the distinction between similar terms (e.g., authentication vs authorization, IaaS vs PaaS, process vs thread). Don't sacrifice accuracy by rushing; follow the time and navigation rules in your actual test.

## Coverage note

No finite practice bank can contain “every possible” question: an assessment can vary by role, drive, vendor, and question pool. This pack aims for broad foundational coverage and includes explanations so it can teach as well as test. For role-specific preparation, add the skills named in the job description.
