# MS Office and Productivity Tools

## Concepts to learn

- **Word:** Styles provide consistent headings; Find/Replace locates or changes text; page breaks control pagination; comments and Track Changes support review.
- **Access:** A relational database application. Tables store records, queries retrieve/filter data, forms support data entry, and reports format data for viewing/printing.
- **Excel workbook structure:** A workbook contains worksheets; a worksheet contains cells arranged in rows and columns. Cell references identify locations such as `B3`.
- **Excel formulas:** Formulas start with `=`. Relative references change when copied; absolute references such as `$A$1` stay fixed; mixed references fix either row or column.
- **Common Excel functions:** `SUM` totals values, `AVERAGE` computes a mean, `COUNT` counts numeric cells, `COUNTA` counts nonempty cells, and `IF` returns a result based on a condition.
- **Sorting, filtering, charts:** Sorting changes order; filtering hides rows not meeting criteria; charts visualize data and should match the data type/message.
- **PowerPoint:** Themes/layouts create consistent visual structure; transitions occur between slides; animations affect objects on a slide.
- **Publisher:** A desktop-publishing tool for page-layout materials such as flyers, brochures, and newsletters. It is not the same thing as PowerPoint slide authoring.
- **Outlook/email:** To is the primary recipient; Cc shares a visible copy; Bcc hides recipients from other recipients. Verify recipients and attachments before sending.
- **Collaboration:** Version history, comments, and controlled sharing help collaboration; avoid granting broad access when narrower access works.
- **Keyboard shortcuts:** Shortcuts can vary by operating system and application version; learn common actions and confirm against your setup.

## Original practice MCQs

### Questions

1. In Excel, which function adds values in a range?
   A) `SUM`  B) `COUNT`  C) `MAXTEXT`  D) `JOIN`

2. What does `$A$1` represent in an Excel formula?
   A) Fully absolute row and column reference
   B) Relative reference to any cell
   C) A worksheet name
   D) A chart title

3. Which function counts non-empty cells, including text?
   A) `COUNT`  B) `COUNTA`  C) `SUM`  D) `AVERAGE`

4. In an email, which field hides the listed recipients from other recipients?
   A) To  B) Cc  C) Bcc  D) Subject

5. In PowerPoint, a transition is an effect applied primarily:
   A) Between slides  B) To a database row  C) To email recipients  D) To an Excel formula

6. What is the main purpose of Word's Track Changes feature?
   A) Record edits for review  B) Calculate averages  C) Encrypt a network  D) Create a mail server

7. An Excel formula `=IF(B2>=50,"Pass","Review")` returns "Pass" when:
   A) B2 is less than 50  B) B2 is at least 50  C) B2 is blank only  D) The workbook closes

8. Which Excel feature temporarily shows only rows meeting selected criteria?
   A) Filter  B) Slide transition  C) Page margin  D) Mail merge

9. In a relational table, what is the usual purpose of a primary key?
   A) Uniquely identify each record  B) Add slide animations  C) Format a page  D) Send an email

10. Which application is the closest fit for designing a multi-panel brochure with precise page layout?
    A) Publisher  B) Calculator  C) Outlook  D) Notepad

### Answer key and explanations

1. **A — SUM.** `SUM` adds numeric values in one or more cells/ranges.
2. **A.** Dollar signs lock both column A and row 1 when a formula is copied.
3. **B — COUNTA.** It counts non-empty cells; `COUNT` counts numeric cells.
4. **C — Bcc.** Blind carbon-copy recipients are not shown to other recipients.
5. **A.** Transitions control movement from one slide to the next; animations apply to objects on a slide.
6. **A.** Track Changes records edits so reviewers can accept or reject them.
7. **B.** The logical test is true when `B2 >= 50`.
8. **A — Filter.** Filtering hides nonmatching rows without deleting them.
9. **A.** A primary key uniquely identifies a row in a table.
10. **A — Publisher.** It is designed for desktop-publishing layouts such as brochures and flyers.
