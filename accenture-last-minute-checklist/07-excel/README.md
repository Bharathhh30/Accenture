# Excel

**Assessment priority: High evidence as part of MS Office/Common Applications** — formula basics and data handling are the safest revision targets.

| Concept | One-line last-minute reminder |
|---|---|
| Workbook and worksheet | A workbook contains worksheets; each worksheet has rows, columns, and cells. |
| Cell reference | A cell address combines column and row, such as `B3`. |
| Formula | An Excel formula begins with `=` and can combine values, references, operators, and functions. |
| Relative reference | `A1` changes row/column when a copied formula moves. |
| Absolute reference | `$A$1` locks both column and row when the formula is copied. |
| Mixed reference | `$A1` locks the column; `A$1` locks the row. |
| SUM | `SUM(range)` adds numeric values in the referenced range. |
| AVERAGE | `AVERAGE(range)` calculates the arithmetic mean of numeric values. |
| COUNT vs COUNTA | `COUNT` counts numeric cells; `COUNTA` counts non-empty cells. |
| COUNTIF / SUMIF | `COUNTIF` counts cells meeting a criterion; `SUMIF` adds values matching a criterion. |
| IF | `IF(test, value_if_true, value_if_false)` selects a result based on a logical test. |
| AND / OR | `AND` is true only when all conditions are true; `OR` is true when at least one is true. |
| Lookup functions | `VLOOKUP` searches the first column of a range; `XLOOKUP` is a newer flexible lookup available in supported versions. |
| Sort | Sorting changes the order of rows based on selected column values. |
| Filter | Filtering hides rows that do not match criteria without deleting the underlying data. |
| Remove Duplicates | Remove Duplicates deletes repeated records based on selected columns; keep a backup if original data matters. |
| Conditional formatting | Conditional formatting changes cell appearance when rules/values meet criteria. |
| Data validation | Data validation restricts acceptable cell entries, such as a list or numeric range. |
| PivotTable | A PivotTable summarizes and rearranges large tabular datasets by fields and aggregate values. |
| Chart choice | Choose a chart that fits the comparison/trend/composition being communicated. |
| Text functions | `LEFT`, `RIGHT`, `MID`, `LEN`, and `TRIM` extract or clean text in common ways. |
| Date functions | Dates are stored as serial values in Excel; date functions operate on that underlying representation. |
| Errors | `#DIV/0!`, `#N/A`, `#VALUE!`, `#REF!`, and `#NAME?` signal different formula/reference problems. |
| Freeze Panes | Freeze Panes keeps selected rows/columns visible while scrolling. |
| Tables | Excel Tables add structured references, automatic expansion, and integrated filtering/sorting. |
| Save and sharing | Confirm file format, save location, version, and recipient access before sharing workbooks. |
