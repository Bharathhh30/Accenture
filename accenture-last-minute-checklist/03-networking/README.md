# Networking

**Assessment priority: High evidence** — networks are named in candidate accounts and network fundamentals appear in preparation outlines.

| Concept | One-line last-minute reminder |
|---|---|
| OSI model | Memorize Physical, Data Link, Network, Transport, Session, Presentation, Application in order. |
| TCP/IP model | Map Link, Internet, Transport, and Application to the practical Internet protocol stack. |
| Encapsulation | Each layer wraps data with its own control information as data moves down the stack. |
| LAN / WAN | A LAN covers a limited local area; a WAN connects networks over larger geographic areas. |
| MAC address | A MAC address identifies an interface for local-link delivery. |
| IP address | An IP address provides logical addressing used for routing between networks. |
| IPv4 subnet/CIDR | CIDR prefix length specifies network bits; for example, a conventional `/24` has 256 total IPv4 addresses. |
| Private vs public IP | Private IPv4 ranges are for internal networks and are not globally routed on the public Internet. |
| Subnet mask | A subnet mask/prefix separates network bits from host bits in an IP address. |
| Switch | A Layer-2 switch forwards Ethernet frames within a LAN using learned MAC addresses. |
| Router | A router forwards IP packets between networks using routing information. |
| Layer-3 switch | A Layer-3 switch can also route; read whether a question refers to Layer-2 forwarding or inter-network routing. |
| ARP | ARP resolves an IPv4 address to a link-layer address on a local network segment. |
| DNS | DNS resolves domain names to records such as IP addresses. |
| DHCP | DHCP leases network settings such as IP address, subnet mask, gateway, and DNS server. |
| TCP | TCP provides connection-oriented, ordered, reliable byte-stream delivery. |
| UDP | UDP is connectionless and lower-overhead, with no built-in guarantee of delivery or ordering. |
| HTTP / HTTPS | HTTPS is HTTP protected by TLS for transport confidentiality/integrity and server authentication. |
| TLS certificate | A certificate binds an identity to a public key and is validated through a trust chain. |
| Port number | A port identifies a transport-layer service endpoint on a host; it is not an IP address. |
| Common ports | Common defaults include DNS 53, HTTP 80, HTTPS 443, SSH 22, and SMTP 25; verify protocol/context in the question. |
| NAT | Network Address Translation rewrites address information, commonly allowing private hosts to share public IPv4 addresses. |
| Firewall | A firewall allows or blocks traffic according to configured policy and context. |
| VLAN | A VLAN logically separates Layer-2 broadcast domains on switching infrastructure. |
| Bandwidth vs latency | Bandwidth is data capacity; latency is the delay before/while data arrives. |
| Packet loss | Packet loss is data not reaching its destination and can trigger retransmission or degrade real-time media. |
