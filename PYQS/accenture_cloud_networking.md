# Accenture Cloud & Networking 25 Most Repeated Questions

---

### **Question 1: Cloud Computing Core Capabilities**

What does cloud computing primarily provide to users?

* A) Physical hardware only
* B) Computing resources over the internet
* C) Offline software installations
* D) Local antivirus protection

**Answer:** **B) Computing resources over the internet**

* **Explanation:** Cloud computing delivers computing services—including servers, storage, databases, networking, and software—over the internet ("the cloud") on a pay-as-you-go basis.

---

### **Question 2: SaaS (Software as a Service) Identification**

Which of the following is an example of Software as a Service (SaaS)?

* A) Amazon EC2
* B) Google App Engine
* C) Gmail
* D) Virtual Machine

**Answer:** **C) Gmail**

* **Explanation:** Gmail is a fully managed, end-user web application hosted entirely by Google. You do not manage operating systems, runtime, or infrastructure.
* **Other Options:**
* *Amazon EC2:* Infrastructure as a Service (IaaS).
* *Google App Engine:* Platform as a Service (PaaS).



---

### **Question 3: Cloud Abstraction Terminology**

What is the full form of **PaaS**?

* A) Platform as a Service
* B) Program as a Service
* C) Process as a Service
* D) Protocol as a Service

**Answer:** **A) Platform as a Service**

* **Explanation:** PaaS provides a managed framework and runtime environment where developers can build, test, deploy, and manage applications without maintaining the underlying virtual servers or network infrastructure.

---

### **Question 4: IaaS (Infrastructure as a Service) Identification**

Which of the following cloud services is an example of IaaS?

* A) Google Docs
* B) Amazon EC2
* C) Salesforce
* D) Zoom

**Answer:** **B) Amazon EC2**

* **Explanation:** Amazon EC2 (Elastic Compute Cloud) lets users rent virtual servers (instances) on demand, giving them full administrative control over the operating system, storage, and networking layers.

---

### **Question 5: Infrastructure Control Across Cloud Service Models**

Which cloud service model gives the user the **most** administrative control over the infrastructure?

* A) SaaS
* B) PaaS
* C) IaaS
* D) FaaS

**Answer:** **C) IaaS**

* **Explanation:** In IaaS, users manage the OS, middleware, runtime environments, and application data while the cloud vendor manages physical hardware and virtualization layers. In PaaS and SaaS, the user has progressively less infrastructure control.

---

### **Question 6: Cloud Deployment Models - Single Tenant**

Which cloud deployment model is dedicated strictly to a single organization?

* A) Public Cloud
* B) Private Cloud
* C) Hybrid Cloud
* D) Community Cloud

**Answer:** **B) Private Cloud**

* **Explanation:** A Private Cloud is dedicated solely to a single organization, either hosted on-premises or managed by a third-party, offering higher isolation and security control.

---

### **Question 7: Hybrid Cloud Architecture**

Which cloud model combines both public and private cloud environments?

* A) Distributed Cloud
* B) Hybrid Cloud
* C) Multi-tenant Cloud
* D) Community Cloud

**Answer:** **B) Hybrid Cloud**

* **Explanation:** A Hybrid Cloud connects private infrastructure (on-premises or private cloud) with public cloud services, allowing data and applications to be shared between them.

---

### **Question 8: Benefits of Cloud Computing**

What is considered a major operational advantage of cloud computing over traditional on-premises setups?

* A) Infinite physical hard disk durability
* B) Scalability
* C) Elimination of internet requirements
* D) Zero maintenance requirements

**Answer:** **B) Scalability**

* **Explanation:** Scalability allows cloud resources (CPU, RAM, storage) to automatically scale up or down dynamically based on user demand (e.g., handling peak sales traffic on e-commerce sites).

---

### **Question 9: Definition of Cloud Scalability**

What does **scalability** mean in the context of cloud computing?

* A) Increasing network cable bandwidth physically
* B) Dynamically increasing or decreasing resources based on demand
* C) Buying permanent hardware units
* D) Encrypting databases

**Answer:** **B) Dynamically increasing or decreasing resources based on demand**

* **Explanation:** Cloud scalability gives businesses the agility to expand compute capacity during peak demand and reduce capacity during low-traffic periods to save costs.

---

### **Question 10: Virtualization Concept**

What is **virtualization** in cloud computing?

* A) Destroying physical servers
* B) Creating virtual versions of computing resources on a single physical machine
* C) Connecting devices using ethernet cables
* D) Installing local antivirus firewalls

**Answer:** **B) Creating virtual versions of computing resources on a single physical machine**

* **Explanation:** Virtualization enables a single physical computer to act as multiple isolated Virtual Machines (VMs), each running its own operating system independently.

---

### **Question 11: Virtual Machine Management Component**

Which software layer creates, runs, and manages Virtual Machines (VMs)?

* A) Firewall
* B) Router
* C) Hypervisor
* D) Compiler

**Answer:** **C) Hypervisor**

* **Explanation:** A **Hypervisor** (or Virtual Machine Monitor/VMM) sits between the hardware and the virtual environments, allocating physical hardware resources (RAM, CPU) to guest VMs.

---

### **Question 12: Pay-As-You-Go Billing Model**

What does the "Pay-As-You-Go" pricing model in cloud computing mean?

* A) Fixed flat-rate annual payment
* B) Free cloud computing for all users
* C) Paying only for the cloud resources consumed over a given period
* D) Mandatory upfront hardware purchases

**Answer:** **C) Paying only for the cloud resources consumed over a given period**

* **Explanation:** Users pay strictly for the actual compute hours, storage size, or network bandwidth consumed, preventing wasted capital on unused infrastructure.

---

### **Question 13: Type-1 (Bare-Metal) Hypervisor Identification**

Which of the following is an example of a **Type-1 (Bare-Metal) Hypervisor**?

* A) Oracle VirtualBox
* B) VMware ESXi
* C) Google Chrome
* D) VLC Media Player

**Answer:** **B) VMware ESXi**

* **Explanation:** Type-1 hypervisors (e.g., VMware ESXi, Microsoft Hyper-V, KVM) run directly on the host's physical hardware without needing an underlying host operating system.

---

### **Question 14: Type-2 (Hosted) Hypervisor Identification**

Which component is an example of a **Type-2 (Hosted) Hypervisor**?

* A) VMware ESXi
* B) Oracle VirtualBox
* C) BIOS
* D) Network Router

**Answer:** **B) Oracle VirtualBox**

* **Explanation:** Type-2 hypervisors run on top of an existing host operating system (e.g., VirtualBox running on Windows or macOS), making them common for local development and testing.

---

### **Question 15: AWS Object Storage Services**

Which AWS service is specifically designed for secure object storage (files, images, backups)?

* A) EC2
* B) Amazon S3
* C) AWS Lambda
* D) Amazon RDS

**Answer:** **B) Amazon S3**

* **Explanation:** **Amazon S3** (Simple Storage Service) is an object storage service designed to store and retrieve unstructured data files, static media, and backups.

---

### **Question 16: Networking Terminology - LAN**

What does **LAN** stand for?

* A) Large Area Network
* B) Local Area Network
* C) Local Access Network
* D) Logical Area Network

**Answer:** **B) Local Area Network**

* **Explanation:** A LAN connects computers and devices within a limited geographical area, such as a single home, school, or office building.

---

### **Question 17: Networking - Inter-Network Connection Devices**

Which networking device connects different networks together and forwards data packets between them?

* A) Switch
* B) Router
* C) Repeater
* D) Network Interface Card (NIC)

**Answer:** **B) Router**

* **Explanation:** A **Router** operates at Layer 3 (Network Layer) of the OSI model and inspects IP addresses to route data packets between different networks (e.g., connecting a local home network to the Internet).

---

### **Question 18: OSI Layer 2 Devices**

Which networking device operates primarily at **Layer 2 (Data Link Layer)** of the OSI Model?

* A) Router
* B) Switch
* C) Hub
* D) Gateway

**Answer:** **B) Switch**

* **Explanation:** Layer 2 network switches receive data in the form of **Frames** and forward them to target devices within the same network using hardware **MAC Addresses**.

---

### **Question 19: OSI Model - Packet Routing Layer**

Which layer of the OSI Model handles logical addressing (IP addresses) and routing of packets?

* A) Layer 1 - Physical Layer
* B) Layer 2 - Data Link Layer
* C) Layer 3 - Network Layer
* D) Layer 4 - Transport Layer

**Answer:** **C) Layer 3 - Network Layer**

* **Explanation:** The Network Layer is responsible for packet delivery, logical IP addressing, and determining the optimal path (routing) across interconnected networks.

---

### **Question 20: Address Resolution Protocol (ARP)**

Which protocol resolves a known **IP Address** into a physical **MAC Address** on a local network?

* A) DNS
* B) ARP
* C) DHCP
* D) ICMP

**Answer:** **B) ARP (Address Resolution Protocol)**

* **Explanation:** ARP maps a Layer 3 logical IP address to a Layer 2 physical MAC address so that data frames can be delivered to the correct hardware interface.

---

### **Question 21: Domain Name System (DNS)**

Which protocol translates human-readable domain names (e.g., `google.com`) into computer-readable IP addresses?

* A) ARP
* B) DNS
* C) DHCP
* D) FTP

**Answer:** **B) DNS (Domain Name System)**

* **Explanation:** DNS acts as the "phonebook of the Internet," translating domain names into numerical IP addresses so browsers can load internet resources.

---

### **Question 22: Dynamic Host Configuration Protocol (DHCP)**

What is the primary function of **DHCP** in a network?

* A) Translating domain names to IP addresses
* B) Automatically assigning dynamic IP addresses and network configurations to devices
* C) Securing web traffic over HTTPS
* D) Routing data packets across networks

**Answer:** **B) Automatically assigning dynamic IP addresses and network configurations to devices**

* **Explanation:** DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses, subnet masks, default gateways, and DNS servers to devices when they connect to a network.

---

### **Question 23: Network Address Translation (NAT)**

A local device uses a private IP address `10.0.0.25`. When communicating across the public Internet, its traffic is mapped to a public IP address. What technology performs this mapping?

* A) DHCP
* B) NAT
* C) DNS
* D) VLAN

**Answer:** **B) NAT (Network Address Translation)**

* **Explanation:** **NAT** translates private (non-routable) IP addresses from a local network into a single or shared public IP address for safe communication over the public Internet.

---

### **Question 24: Transport Layer Protocols - UDP Characteristics**

Which statement regarding the **User Datagram Protocol (UDP)** is true?

* A) UDP provides guaranteed delivery and packet ordering
* B) UDP uses a 3-way handshake to establish connections
* C) UDP has lower protocol overhead than TCP because it is connectionless
* D) UDP is slower than TCP

**Answer:** **C) UDP has lower protocol overhead than TCP because it is connectionless**

* **Explanation:** UDP is a connectionless, lightweight protocol that does not require connection handshakes, delivery acknowledgments, or sequence ordering, making it faster for real-time applications like online gaming and live streaming.

---

### **Question 25: WAN Scope**

Which network type spans large geographic areas, such as entire countries or continents?

* A) PAN
* B) LAN
* C) MAN
* D) WAN

**Answer:** **D) WAN (Wide Area Network)**

* **Explanation:** A **WAN** (Wide Area Network) connects multiple smaller networks (LANs/MANs) across vast geographical distances (e.g., the global Internet).
