### **5. Networking - Connection Tracking**

What type of table tracks active network connections and their current states?

* A) Routing Table
* B) State Table (Stateful Inspection Table)
* C) MAC Address Table
* D) ARP Table

**Answer:** **B) State Table (Stateful Inspection Table)**

* **Explanation:** Stateful firewalls maintain a **State Table** that keeps track of active connections, including IP addresses, port numbers, and current session states (e.g., `ESTABLISHED`).

### **6. MS Excel - Combining Text Strings**

* A) PROPER
* B) CONCATENATE
* C) TRIM
* D) TEXT

**Answer:** **B) CONCATENATE**

* B) Network Layer

**Answer:** **C) Transport Layer**

### **22. Network Types - Geographic Scope**

What is the correct ascending order of computer networks by geographical area size?

* A) LAN $\rightarrow$ PAN $\rightarrow$ MAN $\rightarrow$ WAN
* B) PAN $\rightarrow$ LAN $\rightarrow$ MAN $\rightarrow$ WAN
* C) PAN $\rightarrow$ MAN $\rightarrow$ LAN $\rightarrow$ WAN
* D) WAN $\rightarrow$ MAN $\rightarrow$ LAN $\rightarrow$ PAN

**Answer:** **B) PAN $\rightarrow$ LAN $\rightarrow$ MAN $\rightarrow$ WAN**

* **Explanation:**
1. **PAN (Personal Area Network):** Personal space (~10m).
2. **LAN (Local Area Network):** Single office, house, or building.
3. **MAN (Metropolitan Area Network):** Spans a city or town.
4. **WAN (Wide Area Network):** Spans global areas, countries, or regions.
